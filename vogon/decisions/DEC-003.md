# DEC-003: The test manager produces the traceability report where one exists

Where a test manager is configured, it produces the traceability report, and
VOGON builds the matrix only where none is configured.

**Context.** A traceability matrix can be computed from the test markers and a
JUnit XML file, and a test manager computes it from the results uploaded to it.

**Options.**

VOGON builds the matrix in every project. One format everywhere, and VOGON code
becomes the source of validation evidence in projects that already have a
validated tool for it.

The test manager produces the report, and VOGON builds the matrix only where no
test manager exists. Two formats of matrix exist across projects.

**Decision.** Where a test manager is configured, VOGON uploads the JUnit XML
unchanged and the test manager produces the report. Where none is configured,
`vogon trace` joins the markers and results of one commit into the matrix.

**Consequences.** Projects with and without a test manager file matrices in
different formats. A requirement with no item in the test manager is missing
from its report.

**Example.** A project with a test manager uploads the results of the release
commit to it and files the report it produces. A project without a test manager
files the output of `vogon trace`.
