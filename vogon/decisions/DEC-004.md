# DEC-004: Version 0.1 is tested against one stack and has no abstraction layer

Version 0.1 is developed and tested against one stack, and no abstraction
layer is written before a second implementation exists.

**Context.** Trackers, test managers and coding agents differ. An interface
written now would let a second product be added later. The host project's
validation plan chooses the tracker, test manager, document system and
repository host.

**Options.**

Define a tracker interface and a test manager interface now, each with one
implementation. The interface is shaped by the only implementation, so a
second product usually does not fit it.

Write for one stack, and write an interface when a second implementation is
needed. A second implementation needs a refactor.

**Decision.** Version 0.1 is developed and tested against Python with pytest,
GitHub, Jira, Xray and Claude Code. No abstraction layer is written before a
second implementation exists. The skills reach the tracker, test manager,
document system and repository host by role, through the system
`vogon/project/vogon.yaml` names for the role, because the validation plan
chooses the products. Where no tracker holds approvals, `vogon approve` records
them. Where no test manager is configured, `vogon trace` builds the matrix.

**Consequences.** The code is smaller, and every path in it is exercised. A
product other than the tested ones is reached through its role and is
untested by VOGON. A host project in another language or with another test
framework needs a refactor.

**Example.** A host project tested with unittest instead of pytest is outside
version 0.1: its tests carry no `req` marker, and `vogon trace` has nothing to
join.
