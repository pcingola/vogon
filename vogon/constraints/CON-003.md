# CON-003 — The repository is not the system of record for approval

Approval state lives in the tracker. A record in the repository may carry the
key of the issue that governs it and a copy of the approval state read from
that issue, and it may not carry a hand-written assertion that it was approved.

Git records what changed, not who changed it or when, and a commit is not a
signature. A repository that claimed approval would be asserting something it
cannot evidence.

**Example.** A record's frontmatter names its tracker key. Whether that issue
is approved is answered by asking the tracker, not by reading the file.
