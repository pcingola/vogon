# CON-001 — Approval cannot be performed by a machine account

Approval and signature are performed by a named person entering their own
credentials in the system of record. No credential held by VOGON, no service
account and no automation may apply one.

This forbids VOGON transitioning an issue into a state that records approval,
even where the tracker's permissions would allow it, and even where a person
has asked for it. The signature is the mechanism by which someone is
answerable, and an automated one names nobody.

**Example.** A run that has created forty requirement issues leaves all forty
awaiting a human transition. There is no flag that approves them.
