# CON-001: Approval cannot be performed by a machine account

VOGON never moves a tracker item through an approval or signature transition.

Such a transition requires the signer's own credentials. VOGON does not make
it, even where the tracker permissions allow it or a person asks for it.
`vogon approve` only writes to the state file an approval that the requirement
approver gave in their own instruction. The record carries the approver's git
identity and is not an electronic signature. No copy of the two regulations is
held in `vogon/sources/`, so the record has no `source`.

**Example.** A run drafts forty requirements. All forty stay unapproved until
the requirement approver gives an instruction that names them, by id or as a
set.
