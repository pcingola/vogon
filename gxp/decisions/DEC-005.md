# DEC-005 — VOGON does not call a language model

**Context.** Turning a transcript into draft records is the step that saves the
most time, and it is a language task. It could run inside VOGON as a command,
or outside it in the coding agent already working in the repository.

**Options.**

A `vogon draft` command that calls a model. One command for the user, at the
cost of credentials in the tool, non-deterministic output from a command line,
and a tool that both writes records and judges them.

Ship the instructions, let the coding agent draft, and validate the result.

**Decision.** No VOGON command calls a language model. VOGON ships the
instructions a coding agent follows, and validates what the agent wrote.

**Consequences.** Every command is deterministic and testable, VOGON needs no
model credentials, and the checker can disagree with the draft because it did
not produce it. The user needs a coding agent to get the drafting benefit,
which version 0.1 assumes they have. A project that wants unattended drafting
has to script the agent itself.

**Example.** `vogon check` runs offline, with no model credentials configured, and
validates every record. Asking the same command to draft a requirement from a
transcript fails: that work belongs to the coding agent.
